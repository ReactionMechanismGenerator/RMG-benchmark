# RMG-benchmark

Benchmarks for the RMG v3.3 paper, comparing it against historical versions of RMG.

## Installing

Need four separate envs.


2.4.1 which was the last Python 2 release using Python 2.7 https://github.com/ReactionMechanismGenerator/RMG-Py/tree/af0ef48bda472c4689605015ac0adda102425aae
3.0.0 which was the first Python 3 release using Python 3.7 https://github.com/ReactionMechanismGenerator/RMG-Py/tree/756c968b5a053f794a5a33dd9a292f602cb1e83a
3.3.0 wich is the version described in this manuscript, specfically running Python 3.11
3.3.0 with Python 3.11, using the optional \rms{} backend for reactor simulations
